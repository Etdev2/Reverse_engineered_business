# Reverse_engineered_business

Reverse-engineered ideation for a logistics-operations founder (ocean freight
forwarding, customs brokerage, port drayage): 15 hrs/week, $5k capital,
no-code + basic Python, direct B2B outbound.

## Deliverables

- **[Full analysis — Phases 2–4](docs/reverse-engineered-logistics-business.md)**
  - Phase 2: 8 candidate businesses, each mapped pain × buyer × proven invoice × delivery engine × first-dollar wedge
  - Phase 3: weighted scoring against the fixed constraints (matrix + rationale)
  - Phase 4: the pick, 90-day execution plan, $5k budget, offer terms, stage gates, cold-outbound scripts, 12-month roadmap
- **[Scoring matrix (CSV)](data/scoring-matrix.csv)** — sortable scores for all 8 candidates
- **[D&D reconciler MVP (Python, zero dependencies)](tools/dnd_reconciler.py)** — runnable proof-of-concept for the winning candidate's file parser, with sample data in `tools/sample_data/`

**Bottom line:** start a pure-contingency detention/demurrage recovery desk for
$10–100M importers (weighted score 9.10/10); let the audits fund and train a
parser SaaS sold to forwarders by month 4; add chassis "ghost day" recovery as
the second vertical. The manual LCL monitoring and ISF concierge ideas are
rejected because their operating shapes breach the 15-hour-week constraint.
